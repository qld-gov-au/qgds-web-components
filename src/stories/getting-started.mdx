# QGDS Web Components

Start here to install, register, and use QGDS Web Components in your app.

## Install

```bash
npm install @qld-gov-au/qgds-web-components
```

## Import Styles

QGDS Web Components require a global stylesheet to render with correct typography, spacing, and colours. Import the stylesheet in your app entrypoint:

```ts
import "@qld-gov-au/qgds-web-components/styles.css";
```

## Import Components

Components are self-registering, they'll be available for use as soon as you import them.

```js
// import all components
import "@qld-gov-au/qgds-web-components";

// or, import just the components you need
import "@qld-gov-au/qgds-web-components/button";
import "@qld-gov-au/qgds-web-components/callout";
import "@qld-gov-au/qgds-web-components/inpage-nav";
```

## Use a Component

```html
<qgds-button label="Continue"></qgds-button>
```

## Hello world

```html
<html>
  <head>
    <script type="module">
      import "@qld-gov-au/qgds-web-components/styles";

      import "@qld-gov-au/qgds-web-components/button";
      import "@qld-gov-au/qgds-web-components/callout";
    </script>
  </head>
  <body class="qgds">
    <h1>Hello world</h1>
    <qgds-callout heading="Notice">This is the QGDS Callout component.</qgds-callout>
    <qgds-button label="Continue"></qgds-button>
  </body>
</html>
```

## Accessibility

Components are built with accessibility in mind. Accessible outcomes still depend on:

- semantic page structure
- meaningful labels and content
- correct usage in context
