## API Reference

<Markdown>
  {`

| CSS Class        | Description                                                                                            |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| \`qgds\`         | QGDS styling is applied to any container using the qgds class. This is normally added to the body tag. |
| \`qgds-content\` | Ensure correct vertical rhythm and spacing between typography and components.                          |

`}
