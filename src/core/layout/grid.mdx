## API Reference

<Markdown>
  {`

| CSS Class               | Description                                                                                                                                                                 | Responsive? |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| \`qgds-cols\`           | Base class to apply grid system. Required in addition to any additional modifiers. Defaults to 4 columns on small screens, 6 on medium up (700px) and 12 on lg and up (992) | n/a         |
| \`qgds-cols-{1-12}\`    | Customise the number of columns in the grid, from 1-12.                                                                                                                     | yes         |
| \`qgds-cols-auto-fill\` | Base class to apply grid system. Required in addition to any additional modifiers.                                                                                          | no          |
| \`qgds-cols-auto-fit\`  | Base class to apply grid system. Required in addition to any additional modifiers.                                                                                          | no          |
| \`qgds-span-{1-12}\`    | Make a child item span a specific number of columns.                                                                                                                        | yes         |

`}
